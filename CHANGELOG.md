# Changelog

All notable changes to the Kahf Ads Compose Multiplatform SDK are listed here. New entries are added
when a version is released.

## 0.2.29

- Added `LeaderboardAdView` (728×90).
- Remaining console output is now shown only when `isDebug` is enabled.
- The example app now runs on iOS and shows one section per ad format.

## 0.2.28

- Maven artifacts and the iOS xcframework are now published from this repository. No credentials are
  needed to consume them.
